## 📌 프로젝트 소개

2022년 러시아-우크라이나 전쟁으로 인해 국제 유가가 급등하면서 국내 유가 역시 빠르게 상승했습니다.  
이에 따라 운전자들은 주유 전 유가를 검색하거나, 주변에서 더 저렴한 주유소를 찾는 행동을 자연스럽게 하게 되었습니다.

당시에는 오ㅇㄴㅇ, 오ㅍㄴ과 같은 유가 정보 서비스가 이미 존재했지만, 실제 사용 과정에서는 다음과 같은 불편함이 있었습니다.

- 유가 정보를 보기까지 화면 이동 단계가 많음
- 로그인 또는 추가 정보 입력이 요구됨
- 광고나 부가 서비스로 인해 핵심 정보 탐색이 지연됨
- 사용자가 원하는 “주변 저가 주유소 확인”까지의 흐름이 길어짐

오일오잉은 이러한 불편을 줄이기 위해 만들었습니다.  
사용자가 앱을 실행하면 현재 위치를 기준으로 주변 주유소와 유가 정보를 바로 확인할 수 있도록 하여, 빠르고 단순한 유가 탐색 경험을 제공하는 것을 목표로 했습니다.

<br/>

## 🎯 프로젝트 목표

오일오잉의 핵심 목표는 **가장 빠르게 유가 정보를 확인할 수 있는 사용자 흐름을 만드는 것**입니다.

이를 위해 다음 기준을 중심으로 서비스를 설계했습니다.

- 앱 진입 직후 유가 정보 제공
- 불필요한 로그인 과정 제거
- 광고나 부가 화면보다 핵심 정보 우선 노출
- 사용자 위치 기반 주변 주유소 탐색
- 저렴한 주유소를 빠르게 비교할 수 있는 화면 구성

<br/>

## ✨ 주요 기능

### 1. 현재 위치 기반 주변 주유소 조회

사용자의 현재 위치를 기준으로 주변 주유소 정보를 조회합니다.  
사용자는 별도의 지역 검색이나 복잡한 설정 없이 앱 실행 후 바로 주변 유가 정보를 확인할 수 있습니다.

### 2. 유종별 가격 정보 제공

휘발유, 경유 등 주요 유종의 가격 정보를 제공하여 사용자가 필요한 유가 정보를 빠르게 비교할 수 있도록 했습니다.

### 3. 저가 주유소 탐색

주변 주유소의 가격 정보를 비교해 상대적으로 저렴한 주유소를 쉽게 찾을 수 있도록 구성했습니다.

### 4. 주유소 상세 정보 확인

주유소명, 위치, 가격 등 주유 전 판단에 필요한 정보를 확인할 수 있습니다.

### 5. 간결한 화면 흐름

유가 정보를 찾기 위해 여러 화면을 거치지 않도록 화면 depth를 최소화했습니다.  
사용자가 앱에 들어온 목적이 “유가 확인”이라는 점에 집중해 핵심 정보를 우선적으로 보여주도록 설계했습니다.

<br/>

## 🧭 서비스 방향

기존 유가 정보 앱들은 다양한 맞춤형 데이터와 부가 기능을 제공한다는 장점이 있습니다.  
하지만 단순히 “지금 주변에서 어디가 저렴한지” 확인하려는 사용자에게는 오히려 많은 기능이 진입 장벽이 될 수 있다고 생각했습니다.

오일오잉은 모든 기능을 많이 제공하는 앱이 아니라,  
사용자가 가장 자주 필요로 하는 정보를 가장 빠르게 보여주는 앱을 지향했습니다.
